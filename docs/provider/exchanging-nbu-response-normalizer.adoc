= Exchanging NBU Response Normalizer

== Purpose

`ExchangeNbuRateResponseNormalizer` centralizes parsing and validation of NBU response payloads.

== Input

* raw NBU payload
* base currency code
* optional fallback date

== Output

`ExchangeNbuRateNormalizedResponseDTO`

Fields:

* `rateValue`
* `rateDate`
* `rawRow`

== Validations

* payload must be an array;
* first row must exist;
* rate must be scalar;
* rate must be numeric;
* exchange date is parsed from `d.m.Y`;
* explicit request fallback date is used when response date is unavailable or invalid;
* missing/invalid response date without an explicit fallback is rejected instead of being relabeled as today's rate.

== Reason for extraction

The provider class remains focused on:

* supports check;
* NBU query construction;
* HTTP fetch;
* mapping normalized response into `ExchangeRemoteRateFetchResultDTO`.

The normalizer owns response validation/parsing only.

== Canon

* normalizer stays in `src/Normalizer`;
* DTO stays in `src/DTO`;
* no `/src/Domain/`;
* no ports-and-adapters architecture.
